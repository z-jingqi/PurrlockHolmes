# 案卷 01「茶点过后」物品清单

按画面里的完整物品计数。轮子、页块、脚垫、绳结、缝线等部件归入所属物品，不重复计算。墙、地板和底座作为一个场景结构，HUD 不计入房间物品。

场景结构包括两面墙、踢脚线、有接缝的木地板和底座。猫的蝴蝶结、小熊爪上的结、车轮和轮毂等是所属物品的细节。底部猫爪收纳匣与数量是界面，不在屋里；屋内的小熊是独立 3D 网格，但仍是不可点选的固定装饰。绳端用同一系绳坐标。

## 这轮核对点

- 移除地毯边没有明确用途、底部也穿入地毯的散落方块；剩余三块积木一起放在木地板上。
- 保留的书都要读得出封皮、书脊与纸边。移除桌上难以辨认的粉色长方体，布餐巾改成可辨认的褶皱和布边。
- 叉子与橘子错位摆放；静止、提示和飞入匣子使用同一份高采样透明图。
- 查看靠枕缝边是否附在布面、拖鞋脚跟是否钝圆、猫抬头是否露出接缝、气球系绳是否穿过小熊脸。
- 按固定视角检查落地与遮挡，在桌面及手机尺寸分别走查点击和六件餐具的通关。
